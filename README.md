# Nataly · Un universo de flores amarillas

Una sola escena a pantalla completa. Se inicia automáticamente al abrir el enlace: flores y fotografías orbitando, video silenciado en bucle y mensajes que cambian solos cada nueve segundos. No hay secciones, menús, enlaces internos, ventanas ni pasos para ver el contenido.

HTML, CSS y JavaScript puros, sin frameworks ni compilación. El universo incluye girasoles, margaritas, rosas y tulipanes amarillos, estrellas y partículas.

La música es opcional y se activa con un toque, según las reglas de audio del navegador. El pequeño botón de pausa detiene la animación, los mensajes y el video. Las preferencias de movimiento reducido ralentizan los movimientos y desactivan las estrellas fugaces.

GitHub Pages publica la rama main desde la raíz. Abrir index.html o servir esta carpeta para una vista local.

Las fotografías y el video pertenecen a sus respectivos titulares; no se concede permiso para reutilizarlos.
